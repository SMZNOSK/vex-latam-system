# Tipografías de THE FINALS

La web oficial https://www.reachthefinals.com/ consultada el 14 de octubre de 2026 declara Saira Extra Condensed para encabezados y Saira Condensed para texto. También carga Poppins para otros elementos.

Estas dos fuentes están guardadas localmente para renderizar sin peticiones de red:

- Saira Extra Condensed 700 (Latin): https://file.squarespace-cdn.com/content/v2/namespaces/fonts/libraries/sqsp/assets/a6620eed-f27d-449e-9a73-56036be7aaf7/latin.woff2
- Saira Condensed 500 (Latin): https://file.squarespace-cdn.com/content/v2/namespaces/fonts/libraries/sqsp/assets/46cce737-dc46-478e-b3c2-c7ae62b30dd5/latin.woff2
