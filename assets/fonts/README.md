# Tipografías de THE FINALS

La web oficial https://www.reachthefinals.com/ consultada el 14 de octubre de 2026 declara Saira Extra Condensed para encabezados y Saira Condensed para texto. También carga Poppins para otros elementos.

Estas dos fuentes están guardadas localmente para renderizar sin peticiones de red:

El rediseño VEX Mono usa Saira Extra Condensed **ExtraBold 800**, descargada sin modificaciones del repositorio de Google Fonts: https://github.com/google/fonts/blob/main/ofl/sairaextracondensed/SairaExtraCondensed-ExtraBold.ttf . Se incluye en `SairaExtraCondensed-ExtraBold.ttf` y reutiliza la licencia OFL de esta familia. La versión 700 se conserva para las plantillas anteriores.

- Saira Extra Condensed 700 (Latin): https://file.squarespace-cdn.com/content/v2/namespaces/fonts/libraries/sqsp/assets/a6620eed-f27d-449e-9a73-56036be7aaf7/latin.woff2
- Saira Condensed 500 (Latin): https://file.squarespace-cdn.com/content/v2/namespaces/fonts/libraries/sqsp/assets/46cce737-dc46-478e-b3c2-c7ae62b30dd5/latin.woff2

Licencia SIL Open Font License incluida para ambas familias, procedente de los directorios `ofl/sairaextracondensed` y `ofl/sairacondensed` del repositorio oficial https://github.com/google/fonts. Los archivos no fueron modificados. Se usa el peso 500 para conservar la legibilidad en tarjetas pequeñas.
