# V1.3 · VEX LATAM SQUAD

La dirección elegida es **01 / Corte**: negro y blanco, planos 2D y Saira Extra Condensed ExtraBold 800. El lema es **No somos solo jugadores, somos VEX.**

## Alta manual y aceptación

En #admin-bot:

    /clan agregar clan:VXTG usuario:@Jugador
    /clan agregar clan:VXLTM usuario:@Jugador embark-id:Jugador#1234 rs:33400

El alta manual no exige formulario ni perfil del bot. Usa el Embark ID y RS del perfil si están disponibles; los campos opcionales permiten indicar otros datos sin modificar ese perfil. Un Embark ID distinto no hereda los RS del anterior. Si faltan datos se muestra «Sin registrar». El rango se calcula con la misma escala del bot; Ruby requiere posición verificada.

El bot comprueba acceso administrativo, presencia en el servidor, rol asignable, membresías duplicadas, Embark IDs duplicados y solicitudes pendientes. Si hay una solicitud pendiente, se debe aprobar desde el receptor o cancelar antes del alta manual. El ingreso registra al operador, asigna el rol y envía el mensaje privado y la bienvenida pública con avatar. Los pasos pendientes se guardan y se reintentan.

Al aprobar un formulario o agregar manualmente se incluye una mención real al jugador en el texto del anuncio. Las ediciones y la recuperación de mensajes existentes desactivan las notificaciones. Los mensajes directos bloqueados no impiden publicar la bienvenida. El contador manual del club dentro del juego se administra por separado.

## Búsqueda por chat

El banco predeterminado incluye **153 frases**, entre ellas variantes de «quién se conecta», «alguien pa rankear», «buscando dúo», «se arma squad», «lfg», «lf1m» y «lf2m». Mantiene una sola búsqueda activa por organizador y omite bots, código, citas, otros juegos reconocidos y negativas de búsqueda.

    /busqueda-chat estado
    /busqueda-chat restablecer
    /busqueda-chat palabras

Una lista personalizada existente se conserva. `restablecer` selecciona el banco amplio y mantiene el estado de activación. El editor admite hasta 250 entradas y 4000 caracteres; los mensajes largos abrevían la vista del embed, conservando la lista completa en el editor. La moderación conserva su límite independiente de 100 entradas / 1000 caracteres.

## Arrancador

`iniciar-bot.cmd` localiza Git aunque la ventana conserve un PATH anterior a su instalación. Si falta, ofrece instalarlo con WinGet o continuar con la versión local. También se puede ejecutar:

    iniciar-bot.cmd --instalar-git

Esa opción prepara únicamente Git; no conecta el bot. Si WinGet no está disponible muestra el [instalador oficial de Git](https://git-scm.com/install/windows). La instalación puede requerir autorización de Windows. No se instala software al ejecutar las pruebas de este proyecto.

La actualización sigue siendo fast-forward: no sobrescribe cambios locales ni resuelve ramas divergentes automáticamente. El token, la configuración local y SQLite no se publican.

## Diseño y activación

Se renuevan los carteles de configurar perfil y buscar equipo, la presentación de clanes y sus tarjetas de ingreso y decisión. Los paneles nativos usan acento blanco. Las tarjetas individuales de patrocinadores conservan su diseño propio. El fondo, la tipografía del chat y los componentes nativos de Discord dependen de Discord.

Las fuentes se incluyen localmente y no se consultan servicios externos al renderizar. Las muestras usan datos ficticios. Para reproducirlas: `node scripts/preview-vex-squad.js`.

Reiniciar el bot carga los comandos y actualiza los paneles con los IDs guardados. Los anuncios antiguos se actualizan en su mismo mensaje, sin repetir la mención. Subir el commit al repositorio no reinicia una instancia que ya está ejecutándose.
